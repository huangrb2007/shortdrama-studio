# 分镜拆分

H3 一次生成一段（≤15 秒）。cut 是段内部的镜头。**分镜的目标不是画面好看，是让观众每两三秒得到一个新信息，并且模型不崩。**

## 最重要的事实：台词是连续铺轨

H3 把段内所有 `<d>` 台词按文本顺序串成一条连续音轨，从第 0 秒开始铺，**不管写在哪个 Shot**。Shot 只决定画面什么时候切。所以：

> **先排音轨，再按音轨切画面。不能先切等长镜头再往里塞台词，那样嘴和人会对不上。**

## 步骤

### 1. 台词账本
列出本段每句：说话人、原文（逐字，不改一个字）、时长（字数 ÷ 3.3，每次换人 +0.3 秒）。累加得到每句的 `speech_start` 和 `speech_end`。总时长占段时长 80–90%。超出就把后面的句子移到下一段，在一句话说完的地方断段。

### 2. 按戏剧节拍断段
每段必须包含一次价值翻转，段尾留一个让人想看下一段的状态。段切点选在：刚说完关键句、刚有新人物或新信息露出。不在一句话中间断。

### 3. 切 cut（默认 5–6 个，尾段按比例减）
**cut 边界落在换人说话处**。每句话归属说出它的那个 cut。无台词的 cut 只放在段首以外的位置，用于反应或揭示；因为音轨从 0 秒开始，第一个 cut 要有第一句台词。

每个 cut 填 `audience_gets`：观众这几秒新得到什么。填不出来就删。

### 4. 定节奏（时长不等）
- 每 cut 2–5 秒，不允许全部等长。
- 信息量决定时长：长台词久，笑点和揭示短。
- 情绪上升段逐渐变短；段尾给揭示留一个 2 秒镜头，含 1 秒定格。

### 5. 定景别（目的是看清谁在反应）
| 用途 | 选择 |
|---|---|
| 说话人抢戏、吐槽 | 中近景 |
| 听话人的反应、受到冲击 | 近景、特写 |
| 关键物件 | 特写 |
| 交代两人位置 | 中景双人 |
| 交代空间 | 远景，**不露正脸**，只拍背影 / 侧影 / 剪影 |

- 相邻 cut 不用同一景别，除非对话段的正反打。
- 15 秒至少用三种景别。
- 对话段固定机位为主；每段最多 1–2 个运镜，必须有动机。

### 6. 一个 cut 一个动作
`primary_action` 只写一个可见动作。两个动作就拆 cut。不写心理：要的是“捏紧手机”，不是“紧张”。

### 7. 空间和人物锁定
先写 `space_anchor`：家具清单、谁在哪、门窗开闭。段内没有走位时，人物的位置和依托物不许变。一镜最多两人入画；第二人只写静止状态。

### 8. 说话和嘴
每句绑定 `speaker`、`on_screen`。入画说话人写可见嘴型；其他入画人物写闭嘴。不入画的人（电话、门外）走画外音，入画的人全程闭嘴。

### 9. 段与段
填 `entry_state` 和 `exit_state`。下一段的入口等于上一段的出口：姿势、位置、手里拿的东西、光线都一样。

## 自检
1. 第一句台词是否在第一个 cut？
2. 所有 cut 时长加起来是否等于段时长？是否不全等？
3. 远景有没有正脸？
4. 每个 cut 只有一个动作吗？
5. 台词和剧本逐字一致吗？

只输出符合 schema 的 JSON。
