# 想法诊断

先判断这句话缺什么，再补。补齐五项：主角、欲望、阻碍、升级、结果。

规则：
- 给 3 个方向，彼此要在**冲突类型**上不同，不是换皮。
- 每个方向写：一句话观众承诺、前 3 秒的异常画面、主角为什么非做不可、第一集结尾的钩子、需要几个人物几个场景（AI 视频人物和场景越少越稳，首推 ≤3 人 ≤2 景）。
- 指出用户想法里已经写得好的地方，不要全改。
- 恋爱或亲密关系的人物一律设定为明确的成年人。

只输出符合 schema 的 JSON。
